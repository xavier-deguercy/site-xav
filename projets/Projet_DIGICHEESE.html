Projet detail

DIGICHEESE

Projet de groupe axe modernisation d'un SI legacy avec API REST, base MySQL, tests et backlog de livraison.

Resume

DIGICHEESE simule la refonte d'un outil historique Access/VBA vers une cible plus propre: API FastAPI, persistance MySQL, documentation et tests.

FastAPI MySQL Pytest Docker
Repo GitHub README

Points cles

  • API REST documentee via Swagger.
  • Ressources Admin en CRUD sur base MySQL.
  • Backlog, suivi et tracabilite des attentes pedagogiques.

Statut: stabilisation et documentation.

Contexte

Probleme simule et objectifs du TP.

  • Moderniser un SI ancien, instable et difficile a maintenir.
  • Fournir une API documentee et testable plutot qu'une IHM complete.
  • Laisser une base de travail claire pour la suite du projet.

Perimetre

Ce qui est livre et ce qui reste hors scope.

Inclus

  • CRUD Admin sur les ressources imposees par le TP.
  • Documentation de demarrage et conventions d'usage.
  • Tests nominaux et tests d'erreur.

Hors scope

  • IHM complete de production.
  • Industrialisation au-dela du cadre pedagogique.
  • Fonctions avancees non demandees par le TP.

Architecture

Vue d'ensemble fonctionnelle et technique.

L'architecture vise a rester simple: endpoints REST, couche metier, persistance MySQL et documentation Swagger.

Contribution personnelle

Ce qui est explicitement mentionne dans le contenu source.

IHM Admin (V1)

Extension front statique de demonstration.

Cette IHM de demonstration ajoute un dashboard, un login a cle API et des ecrans CRUD simples pour montrer l'utilisation des endpoints.

  • Dashboard de statut avec test de sante.
  • Pages CRUD pour Objets et Conditionnements.
  • Stockage local d'une cle `X-API-Key` en contexte de demo.
