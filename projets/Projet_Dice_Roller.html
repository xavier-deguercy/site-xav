Projet detail

Dice Roller

Mini-projet Python utilise pour travailler structure, qualite de code et demonstration reproductible.

Resume

Ce projet sert de support d'entrainement pour consolider la separation des responsabilites, la qualite du code et la documentation d'usage.

Python OOP Tests Documentation
Repo GitHub README

Points cles

  • Organisation lisible pour isoler la logique metier des entrees/sorties.
  • Documentation orientee reproductibilite du clone au lancement.
  • Tests pour securiser le comportement attendu lors des refactors.

Statut: en cours de consolidation.

Contexte

Pourquoi ce projet existe et ce qu'il demontre.

  • Renforcer les bases Python sur un projet court mais exigeant.
  • Produire un livrable portfolio facile a verifier depuis GitHub.
  • Pratiquer un workflow incremental avec backlog et refactor.

Fonctionnalites

Perimetre actuel et axes d'amelioration.

En place

  • Simulation de lancers de des selon plusieurs parametres.
  • Gestion des entrees utilisateur et restitution d'un resultat.
  • Base documentaire pour lancer, comprendre et iterer.

A renforcer

  • Validation plus stricte des erreurs et cas limites.
  • Historique et modificateurs de lancer.
  • Tests complementaires de non-regression.

Qualite et tests

Commandes type de verification.

python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
pytest -q

Architecture

Organisation cible du code et des tests.

L'objectif est de garder une structure qui separe clairement la logique metier, l'interface et les tests.
