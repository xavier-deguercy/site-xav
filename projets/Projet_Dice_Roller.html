Dice Roller (Python)

Mini-projet Python : simulateur de lancers de dés, pensé comme un exercice “pro” (structure, qualité, documentation).

Résumé

Ce projet sert de support d’entraînement pour travailler la qualité de code : organisation du repo, séparation logique des responsabilités, et mise en place de tests sur des cas représentatifs. L’objectif est d’obtenir un livrable clair, reproductible et démontrable sur GitHub.

Qualité & tests

Comment le projet est vérifié (à remplir avec tes commandes réelles).

L’objectif est de pouvoir cloner le dépôt et exécuter les tests facilement. Adapte les commandes ci-dessous à ton README réel. 

# Exemple (à adapter)
# 1) Créer un venv
python -m venv .venv
# 2) Activer (Windows)
.venv\Scripts\activate
# 3) Installer dépendances
pip install -r requirements.txt
# 4) Lancer les tests
pytest -q

Si ton projet n’a pas de dépendances externes, tu peux supprimer la ligne requirements.txt.
